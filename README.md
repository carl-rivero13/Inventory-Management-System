# Inventory-Management-System
Subject Project using Python Django Framework

## Accessing the Python Django File in Local Host ##
1. Open Powershell Windows
2. git clone https://github.com/carl-rivero13/Inventory-Management-System.git
3. Create an environment python -m venv venv
4. venv\Scripts\activate
5. pip install django
6. pip install Pillow
7. cd InventoryManagementSystem
8.  Then run in the local host python manage.py runserver
